# Dynamics 365 Licensing — Master Index

> A structured, **fully-cited** knowledge base for learning everything about
> Microsoft Dynamics 365 licensing. **Every factual claim links back to an
> official Microsoft source** — the *Dynamics 365 Licensing Guide (July 2026)*
> and *Microsoft Learn* — so you can trust it and compile a report from it
> without guesswork.
>
> **Sources policy:** Microsoft-official only. No third-party blogs or resellers.
> **Last updated:** 2026-07-14 · **Licensing Guide version:** July 2026.

---

## How to use this knowledge base

1. Start with the **Fundamentals** to learn the licensing model, license types,
   and the all-important **Base vs Attach** concept.
2. Read the **per-application** files for the products you care about.
3. Use the **Cross-cutting & governance** files for Copilot/AI, Power Platform
   overlap, capacity, compliance, administration, lifecycle, and on-premises.
4. See [`GLOSSARY.md`](./GLOSSARY.md) for definitions and [`SOURCES.md`](./SOURCES.md)
   for the full registry of every official source cited.

### How to generate a comprehensive report from these files
- Each file is self-contained and cited. Concatenate the files in the order
  below (or feed them to an AI) to produce a full report; every statement already
  carries its `[LG p.N]` or `[Learn: …]` citation, so the report is traceable.
- Because Microsoft refreshes the Licensing Guide monthly and changes pricing
  often, treat capacity numbers and offer names as **as-of July 2026** and
  re-verify against the [latest guide](https://aka.ms/dynamicslicensingguide)
  and [pricing pages](https://www.microsoft.com/dynamics-365/pricing-overview)
  before relying on them commercially.
